# TravelKeeper 對照競品 AI 訴求研究報告

來源素材：競品活動主視覺 `D:\威果\1376893.jpg`

## 1. 競品主訴求拆解

海報核心主軸是：

> AI 精準對接，雙向賦能

下方拆成兩大主題、六個賣點：

### 主題一：AI 智慧管理

1. AI 導航：團務控管更穩定
2. AI 串聯：企業流程更順暢
3. AI 接單：業務轉化更快速

### 主題二：AI 商業轉換

4. AI 整合：帳款收付更即時
5. AI 洞察：數據決策更精準
6. AI 全域：高轉單曝光引擎

## 3. 分項分析

### 3.1 AI 導航：團務控管更穩定

競品可能想表達：

- 團體行程進度控管
- 導遊、業務、客服、旅客訊息串接
- 團前提醒、團中服務、團後追蹤
- 異常警示，例如旅客未繳資料、未付款、負評或客訴

TravelKeeper 已有：

- 行程上架與審核
- 行程維護頁，可編輯行程圖片與內文段落
- LINE OA 聊天室監看
- 訪客重要紀錄
- AI 建議回覆
- AI 可根據上架行程提供客服參考
- 重要需求可進 CRM 型資料

缺口：

- 尚未有「團務控管板」
- 沒有團前、團中、團後任務清單
- 沒有旅客資料繳交進度表
- 沒有導遊端服務紀錄
- 沒有團體事件 timeline

建議補強：

新增「團務中心」：

- 行程團號
- 出發日期
- 旅客名單
- 證件 / 付款 / 特殊需求狀態
- LINE OA 對話摘要
- 異常警示
- 導遊服務紀錄

### 3.2 AI 串聯：企業流程更順暢

競品可能想表達：

- CRM、訂單、金流、客服、報表、官網資料打通
- 減少人工轉貼與重複 key in

TravelKeeper 已有：

- Cloudflare Worker API
- D1 作為主要資料庫
- R2 存放行程圖片與檔案
- GAS fallback 過渡
- Wasabi 母站 archival sync
- 分銷商、行程、訂單、佣金、客戶、LINE OA 監看資料
- 圖文選單管理
- Rich Menu publish / stop API
- 管理員 UID 白名單

缺口：

- WeGoTravel 內部營運文件尚未正式融入
- 公司內部業務、查帳、薪資、流水帳尚未落地
- 母站目前偏 archival storage，不是完整商業 API

建議補強：

先接 WeGoTravel 內部營運第一批資料表：

- 員工
- 供應商
- 成本項目
- 付款費率
- 訂單來源

再接內部訂單與查帳。

### 3.3 AI 接單：業務轉化更快速

競品可能想表達：

- AI 讀懂客戶需求
- 推薦合適產品
- 自動產生回覆
- 將對話轉成訂單或商機

TravelKeeper 已有：

- LINE OA 監看頁
- AI 建議回覆
- 行程參考卡
- 可帶入草稿
- 客服可複製或送出回覆
- 推廣行程分享卡
- 六宮格分享版型
- FLEX CARD 綁定推薦碼
- 預約頁建立訂單

缺口：

- AI 尚未自動判斷客戶意圖階段，例如詢價、比價、報名、證件、付款
- AI 尚未把 LINE 對話直接轉成商機卡或訂單草稿
- 尚未有商機漏斗：新客、詢問中、已報價、待付款、已成交

建議補強：

在 LINE OA 監看加「商機狀態」：

- 詢問中
- 已推薦
- 已報價
- 待付款
- 已成交
- 放棄 / 暫緩

並讓 AI 從對話抽取：

- 目的地
- 預算
- 人數
- 日期
- 天數
- 特殊需求

### 3.4 AI 整合：帳款收付更即時

競品可能想表達：

- 付款、查帳、對帳、通知一體化
- 收款後自動更新訂單與業績

TravelKeeper 已有：

- 訂單建立
- 訂金 / 尾款模式
- 可設定允許付款方式
- 藍新金流參數區
- LINE Pay 欄位與付款方式限制
- 金流明細頁
- 尾款收取狀態
- 佣金結算
- 訂單完成後佣金可請款

缺口：

- 藍新正式商店參數尚未確認完整運轉
- 金流 callback / notify 的正式對帳流程需要壓測
- LINE Pay 目前偏欄位與選項，需確認正式 API 是否已串
- 公司內部查帳與付款憑證尚未和 WeGoTravel 文件完全接上

建議補強：

建立「金流驗收清單」：

1. 建單
2. 送藍新
3. 使用測試卡付款
4. callback 寫入 payment_attempts
5. order balance_status 更新
6. 佣金進入 payable
7. 後台金流明細可查
8. 異常付款可人工補登

### 3.5 AI 洞察：數據決策更精準

競品可能想表達：

- 用數據判斷產品、客戶、業務、金流、曝光成效
- AI 產出經營建議

TravelKeeper 已有：

- 管理員總覽
- 訂單管理
- 金流明細
- 佣金結算
- 分銷商列表
- 行程推廣數量
- LINE OA 訪客重要紀錄
- CRM 初步資料
- 母站匯出與 sync map

缺口：

- 缺少「經營洞察儀表板」
- 缺少 AI 每日摘要，例如今日詢問最多的行程、熱門目的地、未回覆客戶
- 缺少轉換率：曝光、點擊、詢問、下訂、付款
- 缺少分銷商排行與行程 ROI

建議補強：

新增「AI 經營洞察」：

- 今日 LINE 詢問數
- 未回覆數
- 熱門目的地
- 熱門行程
- 分銷商成交排行
- 金流未完成警示
- AI 摘要與建議

### 3.6 AI 全域：高轉單曝光引擎

競品可能想表達：

- 多渠道曝光
- AI 推薦與轉單
- 讓產品在 LINE、官網、社群、分銷網絡中擴散

TravelKeeper 已有：

- 分銷商推薦碼
- FLEX CARD 分享
- 六宮格旅遊分享卡
- 分享給好友 / 群組
- 圖文選單管理
- LINE OA 監看
- 分銷商自訂社群連結
- 行程上架與推廣清單

缺口：

- 尚未統計每張卡片分享後的點擊與成交
- 尚未有 A/B 版型測試
- 尚未串社群廣告或再行銷
- 圖文選單與推廣卡尚未形成完整曝光儀表板

建議補強：

新增曝光追蹤：

- 分享卡 ID
- 分銷商 UID
- 行程 ID
- 點擊數
- 進預約頁數
- 建單數
- 付款數
- 轉換率

## 4. 我們可以對外包裝的版本

若要對客戶或合作方說明，建議不要直接說「全部完成」，可以這樣定位：

> TravelKeeper 已具備 AI 行程上稿、LINE OA 客服監看、分銷商推廣、金流與佣金結算的核心底座；下一階段將把團務控管、帳款對帳、AI 洞察與公司內部營運整合成完整旅行社 AI 營運系統。

可主打四個亮點：

1. AI 上稿：PDF / 圖片 DM 轉行程資料、圖片、內文段落。
2. AI 客服：LINE OA 對話監看、建議回覆、行程推薦、重要紀錄。
3. AI 推廣：分銷商推薦碼、FLEX 卡、六宮格分享、圖文選單。
4. AI 營運底座：D1 資料庫、Worker API、R2 圖片、金流與佣金狀態。

## 5. 競品訴求對照結論

TravelKeeper 目前不是單點工具，而是已經往「旅行社 AI 營運系統」方向成形。

和海報上的六個訴求相比：

- 已有基礎：6 / 6
- 可展示：4 / 6
- 可正式稱為閉環：2 / 6

正式閉環較完整的項目：

- AI 串聯
- AI 接單 / 推廣的一部分

仍需補強才適合強打的項目：

- 團務控管
- 帳款即時收付
- 數據洞察
- 全域曝光引擎

## 6. 建議開發優先順序

### 第一優先：讓現有功能變成可驗收閉環

1. 金流正式驗收：藍新與 LINE Pay 狀態閉環。
2. 分享追蹤：分享卡點擊、預約、成交。
3. LINE OA 商機狀態：詢問中、已推薦、待付款、已成交。

### 第二優先：補「AI 洞察」

1. 每日營運摘要。
2. 未回覆警示。
3. 熱門行程與目的地。
4. 分銷商排行。
5. 轉換率漏斗。

### 第三優先：補「團務控管」

1. 團號 / 出發日期。
2. 旅客名單。
3. 證件、付款、特殊需求追蹤。
4. 導遊服務紀錄。
5. 客訴 / 負評警示。

### 第四優先：接 WeGoTravel 內部營運格式

1. 員工、供應商、成本項目、付款費率。
2. 內部訂單。
3. 查帳。
4. 流水帳。
5. 薪資與報表。
